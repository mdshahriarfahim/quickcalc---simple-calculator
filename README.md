## ✨ Features

* **Instant Calculation:** Perform addition, subtraction, multiplication, and division instantly.
* **Calculation History:** Keep track of your recent calculations automatically.
* **Reset Feature:** Clear inputs and results with a single click.
* **Modern UI:** Responsive gradient layout powered by Flexbox & CSS Grid.
* **Input Validation:** Clear warnings for empty or invalid inputs.

---

## 🛠️ Tech Stack

* **HTML5:** Clean markup structure.
* **CSS3:** Modern design, Flexbox, and CSS Grid.
* **JavaScript (ES6):** Interactive UI logic and calculation history management.
* **FontAwesome:** Scalable icons.
